# 周转筐领用与回筐核销台

在「配送任务拖拽排班」基础上扩展的物流周转筐闭环：待分配订单补录配送时段、冷筐/常温筐数与温区，
排班给司机时校验车载额度，发车锁定、改派重算、送达回筐登记、短少破损待回收、核销冻结与更正版本。

- 行业：物流
- 技术栈：React、Vite、TypeScript（未新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

1. **补录**：待分配订单填写配送时段、冷筐数、常温筐数，温区按筐数自动判定（常温/冷藏/混合）。
2. **排班**：同一司机同一时段筐数不得超过车载额度；冷筐与常温筐之和（含待回收占用）不得超过总容量。冲突整次拒绝，表单输入保留。
3. **锁定**：发车前锁定司机、时段与筐数；改派先剔除本单释放原额度，再按新方案重算。
4. **送达**：登记实回与破损筐数；短少（领用−实回）或破损生成待回收记录，继续占用司机总容量额度。
5. **回收**：待回收补录原因后才释放额度；无待回收的已送达订单才能核销。
6. **核销**：核销记录冻结；更正不覆盖原记录，另建 v2、v3… 历史版本全部保留。
7. **刷新一致**：订单、司机额度（实时推导）、回收记录与核销版本整体存入 localStorage，刷新后一致。

## 分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/data.ts` | 司机车辆额度、配送时段、种子数据 |
| 判定 | `src/domain.ts` | 领域类型与纯业务规则（额度、排班、送达、核销） |
| 存储 | `src/storage.ts` | localStorage 整体读写 |
| 页面 | `src/App.tsx`、`src/components.tsx` | 状态编排与界面 |
